§ 00 · The problem

You plug in the monitor. Your windows pile up on one screen. You drag them back, one by one, again.

Deskmap remembers where each one goes, and puts it there.

§ 01 · How it works

Your windows get an address.

Every pin says three things: which display, which desktop, which part of the screen. Each pin has two of those addresses, one for when a monitor is connected and one for the laptop alone. Pull the cable and every window goes to its other address.

  1. 01

    Pin a window by its title

    Click a window on the map and pin it. Deskmap finds a stable key: the file it shows, VS Code's project folder, Terminal's user@host, Safari's tab group. Or pin every window of the app.

  2. 02

    It lives there now

    When the window opens, when it wanders off, after a restart: Deskmap puts it back on its display, its desktop, in its layout.

  3. 03

    Plug in, unplug: it returns

    Monitor connected and Laptop only are two plans. When displays change, Deskmap waits a couple of seconds for them to settle, then places every pinned window where that plan says.

“A pin is a promise about a title. Everything else is drag and drop.”— from the user guide

§ 02 · Features

The map is the app.

No scripts, no config file, no dependencies. You set everything up by clicking and dragging on a map of your displays and desktops.

B2 · Pin by title

Two projects in one app, two different places.

Rules match the window title, not only the app. Two VS Code workspaces or two Safari tab groups can live on two different desktops.

F2 · Profiles

Office, Home, Café. Switch with a click.

A profile is a whole set of pins with a name. Switch from the toolbar, or from a URL.

G1 · Backups

Automatic backups

Every profile, pin and desktop name: hourly (kept a day), daily (kept a week), weekly (kept forever). Restore from Settings › Backups, and undo the restore.

G2 · Undo

Undo instead of dialogs

Multi-step ⌘Z / ⇧⌘Z and a history of this session's changes you can jump back or forward in.

G3 · Automation

deskmap:// URLs

For Shortcuts, Raycast or a terminal.

# switch profile
open "deskmap://profile/Café"
# place everything now
open "deskmap://reapply"
G4 · Small

One small app

Lives in the menu bar, no Dock icon. No scripts, no config file, no dependencies. System Integrity Protection stays on.

§ 04 · Install

Three steps.

macOS 13 or later, Apple silicon and Intel. Deskmap is not notarized yet, so macOS asks you to confirm the first launch.

  1. 01

    Download and drag

    Download the latest release, unzip it and drag Deskmap.app to /Applications.

  2. 02

    Open Anyway

    Open it once. macOS blocks it; go to System Settings › Privacy & Security and click Open Anyway.

  3. 03

    Grant Accessibility

    Turn on Deskmap under Accessibility when the welcome guide asks. It takes it from there.

macOS asks for the Accessibility permission again after each update. To build from source: make app (needs the Xcode Command Line Tools).

§ 05 · Privacy

Collects nothing. Sends nothing. No network code at all.

No analytics, no crash reporter, no update check. Your pins stay in plain JSON files on your Mac that you can read, edit or delete. Don't take our word for it: the source is open, so check it yourself.

Deskmap — zsh
# in a clone of the repository
$ grep -rn 'URLSession\|import Network' app/Sources
# no matches

# what it stores, on your Mac
$ ls ~/Library/Application\ Support/Deskmap

§ 06 · FAQ

Questions, answered.

Anything not covered here is in the user guide, or open an issue on GitHub.

Q.01Why does macOS block the first launch?

Deskmap is not notarized yet. Open it once, then go to System Settings › Privacy & Security and click Open Anyway.

Q.02Why does it need the Accessibility permission?

Without it, no app can see window titles or move windows. It is the only permission Deskmap asks for. macOS asks for it again after each update; if windows stop moving after an update, grant it again.

Q.03What happens when I unplug my monitor?

Every pin has two targets: one for Monitor connected, one for Laptop only. When displays change, Deskmap waits a couple of seconds for them to settle, then puts every pinned window where the plan in effect says.

Q.04Do I need to change any macOS settings?

Four, once, in Desktop & Dock: Automatically rearrange Spaces off, switch to a Space with open windows on, Displays have separate Spaces on, and Group windows by application off (recommended). Deskmap checks these live and tells you which one is wrong. For each app you pin, also set its Dock icon › Options › Assign To to None.

Q.05Do I have to disable System Integrity Protection or write a config?

No. There are no scripts, no config file and no dependencies, and System Integrity Protection stays on. Everything is set up on the map.

Q.06Can I automate it?

Yes. Deskmap answers deskmap:// links, so anything that can open a URL can drive it: deskmap://profile/Café switches profile, deskmap://reapply places everything now, deskmap://toggle pauses or resumes. The reference lists them all.

Q.07Is it really free?

Yes, free and open source under the MIT license. If it saves you time, you can support the project.
