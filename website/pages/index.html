Install

Three steps.
Then never again.

macOS 13 or later, Apple silicon and Intel. Deskmap is not notarized yet, so macOS asks you to confirm the first launch.

  1. 1

    Download and drag

    Download the latest release, unzip it and drag Deskmap.app to Applications.

  2. 2

    Open Anyway

    Open it once. macOS blocks it; go to System Settings › Privacy & Security and click Open Anyway.

  3. 3

    Grant Accessibility

    Turn on Deskmap under Accessibility when the welcome guide asks. It takes it from there.

macOS asks for the Accessibility permission again after each update.

Questions.

Why does macOS block the first launch?

Deskmap is not notarized yet. Open it once, then go to System Settings › Privacy & Security and click Open Anyway.

Why does it need the Accessibility permission?

Without it, no app can see window titles or move windows. It is the only permission Deskmap asks for. macOS asks for it again after each update.

What happens when I unplug my monitor?

Every pin has two targets: one for Monitor connected, one for Laptop only. When displays change, Deskmap waits a couple of seconds for them to settle, then puts every pinned window where the plan in effect says.

Do I have to disable System Integrity Protection or write a config?

No. There are no scripts, no config file and no dependencies, and System Integrity Protection stays on. Everything is set up on the map.

Can I automate it?

Yes. Deskmap answers deskmap:// links: deskmap://profile/Café switches profile, deskmap://reapply places everything now, deskmap://toggle pauses or resumes.

Is it really free?

Yes. Free and open source under the MIT license.
